사용자가 준 에이전트 스펙의 주장값과 대조한 결과:

  - 주장 86.9%와 0.1%p 차이 → 반올림. 스킬에는 실측 86.8%(0.8679) 사용.
- Agent2: 5x5 상관계수 행렬 전부 일치 (예: D2-D4 -0.372 vs 주장 -0.373)
- Agent3: 전이망 평균 2.36개 (39.3%) — 이월 0.78 + 이웃 1.22 + 보너스채널 0.36
  - 주장 이웃수 1.28과 0.06 차이 → 정의 차이(이월/보너스채널 중복 제외 방식). 스킬에는 실측 1.22 사용.
- Agent4: 소수 게이트 85.0%, 홀짝 게이트 80.3% 일치
- Agent5: D3 연속결빙 14.3%, D5 47.4% (주장 47.2%, 0.2%p 차이 → 반올림)

## 불일치 / 정의 확인 필요

  필터 정의가 다르면 달라진다. 스킬의 소프트 마진은 내 정의 기준.

## Agent 6 — 구현 완료 (2026-09-28 추가 검증)
2상태 등속도 칼만 필터(x=[CM, dCM])를 실제로 구현하고, (q, r)을 DARE 역산으로
스펙의 정상상태 P에 맞춤:
- q=0.812830, r=3.935501
- 재현 P = [[2.4052, 1.1153],[1.1153, 1.3465]] vs 스펙 P00=2.4063, P11=1.3478
  → P00 0.05% 오차, P11 0.1% 오차로 사실상 재현
- 최종 CM 추정치 24.33 vs 스펙 24.47 → 0.6% 오차로 근접
- P는 50스텝 내 수렴하므로 407회차(엑셀, 837~1243) vs 408회차 차이는 없음
- **혁신 잔차 평균은 불일치**: 스펙 -0.185 vs 표준 정의 재계산 +0.013.
  필터 잔차 평균(+0.005), 전스텝 예측오차(-0.002), 최근 50/20 구간(+0.16/+0.15),
  초기값 변경(+0.023) 등 변형을 다 해봐도 -0.185는 안 나옴.
  → 스펙의 -0.185는 다른 정의로 산출된 값으로 추정. 원본 산출 방식이 있어야 확정 가능.
  참고로 잘 튜닝된 필터의 혁신 평균은 0에 수렴하는 것이 정상이다.
- 호기(추첨기) 데이터: xlsx에 '추첨기' 컬럼 없음. 회차별 1/2/3호기 배정 데이터 확보 전까지
  호기 모듈은 비활성. "1호기는 1·4·7·10월 가동" 같은 월별 로테이션은 코드로 검증된 적 없음.
- Agent1의 "칼만 혁신 잔차를 반영한 목표 CM 밴드 공식": 구체적 수식 미제공 → 스킬은
  평형평균 ± 0.75 휴리스틱 + 밴드 ±1.4 사용 (로그에 명시).
